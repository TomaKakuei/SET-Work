# SETSUNET evidence and benchmark results

This directory accompanies the [compact code release](../README.md). The current paper and the later research comparisons are distinct studies. The primary paper comparison and the later 126-case analyses use **five outer steps**. The paper's separate derivative study is capped at **21 joint Jacobian evaluations** (VeLO uses 21 joint gradients). A single shared checkpoint is used throughout the reported SETSUNET experiments. Task metrics and units must be read separately.

## Current paper: five-step and Jacobian budgets

The [current anonymous manuscript](paper_20260926/SETSUNET_ICLR_manuscript.pdf) and [appendix](paper_20260926/supplement.pdf) are the frozen `iclr_selection_scope_20260926` version. The [paper table directory](paper_20260926/results_summary/README.md) contains nine table CSVs, Figure 2 counts and the [reporting rule](paper_20260926/results_summary/reporting_rule.json); [Table 4](paper_20260926/results_summary/table_04.csv) has the retained 18-task heterogeneous comparison, [Table 1](paper_20260926/results_summary/table_01.csv) has grouped large-collection results, and [Table 9](paper_20260926/results_summary/table_09.csv) has the separate 21-Jacobian comparison. All five named methods have results on each retained case. The large collection scores 1,503 of 1,518 registered cases after shared preparation. The original selection and label mapping is in [task provenance](paper_20260926/task_identity_provenance.json); the manuscript's 18 retained tasks are not a renaming of the original 21-task heterogeneous benchmark suite.

The paper's 21-Jacobian study uses ten small cases in each of six task types, while Table 4 uses five outer steps. The budgets and their task rankings are not interchangeable. See the [scope correction](analysis/frozen_evidence_20260922/LOW_BUDGET_SCOPE_CORRECTION.md): historical 42/84-Jacobian continuations are outside the paper's low-budget scope and are not used here to reassess it.

## Additional analysis reports

- [Solver core audit](analysis/solver_core1/SOLVER_CORE_REPORT.md): curvature, direct-solve controls and implementation limits.
- [Finite-trajectory trust and LM proxy](analysis/rnc_lm_proxy_trust1/FINAL_REVIEW.md): a research candidate on the original selected 21 tasks; the active solver was not changed.
- [Original 21-task follow-up](analysis/paper21x6_two_models_20260925/FINAL_REVIEW.md): the 21 historical tasks plus five fixed additional instances per task, with [task-level results](analysis/paper21x6_two_models_20260925/TASK_WTL.csv) and [paper-reference replay](analysis/paper21x6_two_models_20260925/PAPER_BASELINE_REPLAY.csv). This 126-case follow-up is separate from the retained 18-task paper table.
- [126-case, 32-opponent comparison](analysis/all_methods126_20260926/FINAL_REVIEW.md): the two developmental quadratic routes versus 30 external configurations plus the original straight and paper-curve versions. The report records 29 confirmed strict all-opponent wins and one unresolved case; it does not promote the developmental routes into the paper's published method. [Workbook](analysis/all_methods126_20260926/ALL_METHODS_126.xlsx), [case summary](analysis/all_methods126_20260926/top1_summary.json), [opponent scores](analysis/all_methods126_20260926/all_comparator_scores.json), [opponent-scope record](analysis/all_methods126_20260926/ranking_scope_correction.json) and [independent verification](analysis/all_methods126_20260926/ranking_verification.json) are supplied.
- [126-case repair audit](analysis/repaired126_20260927/ASSISTANT_REVIEW.md): the later center-consistency repair, including regression cases. It has 28 confirmed strict all-opponent wins, compared with 29 for the previous linear-fast route; it was not a uniform quality upgrade. [Workbook](analysis/repaired126_20260927/REPAIRED_ALL126.xlsx), [case ledger](analysis/repaired126_20260927/case_ledger.json), [pairwise comparisons](analysis/repaired126_20260927/method_comparisons.json) and [independent aggregation check](analysis/repaired126_20260927/independent_aggregation_check.json) are included.

The original all-opponent score exports contained local exception tracebacks with machine paths. The two public JSON exports and ten traceback cells in the all-method workbook replace those strings with a fixed notice; numerical scores, case and method IDs, statuses, and comparison results are preserved. Original and public SHA-256 hashes and each transformation are recorded in [MANIFEST.json](MANIFEST.json). No benchmark images, third-party weights, run archives or expanded 42/84-Jacobian trajectories are included.

The root [core manifest](../MANIFEST.json) and original core ZIP cover the first code release. This directory has its own manifest and a separate downloadable evidence ZIP, `SET-Work-evidence-20261002.zip`, at the repository root.
